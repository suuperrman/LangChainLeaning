# Demo 15: 检索 (Retrieval / RAG)

## 概述

检索通过在查询时获取相关的外部知识，解决 LLM 上下文有限和知识静态的问题。这是 RAG（检索增强生成）的基础。

## 核心知识点

### 1. 检索管道

```
来源 -> 文档加载器 -> 文档 -> 切分成块 -> 转化为嵌入 -> 向量存储 -> 检索器 -> LLM 使用检索到的信息 -> 答案
```

### 2. 构成要素

| 组件 | 描述 |
|---|---|
| 文档加载器 | 从外部源摄取数据，返回标准化 Document 对象 |
| 文本切分器 | 将大文档拆分成更小的块 |
| 嵌入模型 | 将文本转化为数字向量 |
| 向量存储 | 存储和搜索嵌入的专用数据库 |
| 检索器 | 给定非结构化查询，返回文档的接口 |

### 3. 三种 RAG 架构

| 架构 | 描述 | 控制度 | 灵活性 | 延迟 | 适用场景 |
|---|---|---|---|---|---|
| 2 步 RAG | 检索总在生成之前 | 高 | 低 | 快 | FAQ、文档机器人 |
| Agentic RAG | 智能体决定何时和如何检索 | 低 | 高 | 可变 | 研究助理、多工具场景 |
| 混合 RAG | 结合两者，带验证步骤 | 中 | 中 | 可变 | 带质量验证的领域问答 |

### 4. Agentic RAG

智能体只需要访问一个或多个可以获取外部知识的工具（如文档加载器、Web API、数据库查询），即可实现 RAG 行为。
