# Demo 14: 多智能体系统 (Multi-Agent)

## 概述

多智能体系统将复杂应用拆分成多个协同工作的专业化智能体。当单个智能体拥有太多工具或上下文过大时非常有用。

## 核心知识点

### 1. 两种多智能体模式

| 模式 | 工作原理 | 控制流 | 适用场景 |
|---|---|---|---|
| 工具调用 (Tool Calling) | 主管智能体将其他智能体作为工具调用 | 集中式 | 任务编排、结构化工作流 |
| 交接 (Handoffs) | 智能体直接转移控制权给另一个智能体 | 分散式 | 多领域对话、专家接管 |

### 2. 工具调用模式

主管智能体通过 `@tool` 装饰器将子智能体封装为工具：
- 子智能体不直接与用户交谈，只运行任务并返回结果
- 控制流完全通过主管智能体

### 3. 控制子智能体的输入

- **修改提示**: 调整工具名称和描述
- **上下文注入**: 使用 `ToolRuntime` 访问主智能体状态，自定义子智能体的输入

### 4. 控制子智能体的输出

- **修改提示**: 优化子智能体提示，指定应返回什么
- **自定义输出格式化**: 使用 `Command` 对象返回额外的状态和消息

### 5. 上下文工程

多智能体设计的核心是上下文工程——决定每个智能体看到哪些信息：
- 传递给每个智能体的对话/状态的哪些部分
- 为子智能体量身定制的专业提示
- 包含/排除中间推理
- 为每个智能体定制输入/输出格式
